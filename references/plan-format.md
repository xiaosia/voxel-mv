# plan.json 字段

`new_project.py` 会写一份空白的。引擎（`R.run`）、检查脚本都读它。帧号一律是**全曲帧号**（第 n 帧 = 第 n/24 秒）。

| 字段 | 谁用 | 说明 |
|---|---|---|
| `segment`、`maker` | run.py | 交付文件名 `<segment>_<maker>`。单曲 MV 用 `MV` 和片名 |
| `lead` | 你 | 主角 |
| `start`、`end` | 引擎、全部检查 | 本片的帧范围（含头不含尾）。单曲 MV 是 0 和全曲帧数；接力分段是本段的切点 |
| `tempo` | 引擎 | `{beat0, spb}` 固定节拍网格（第 0 拍的秒数、每拍秒数），`beatOf`、踩拍、`beatFrame` 都按它 |
| `cast` | 引擎 | 出场角色（`assets/` 下的文件夹名），只加载这些 |
| `scenes` | 场景关 | `[{id, f0, f1, world, look, why?, same_as?}]`：全片的场景表，从 `start` 连到 `end`。一个场景 = 一套布景（地点 + 光色），10–20 秒左右；`why` 写故意短于 8 秒的原因，`same_as` 标故意回到的前一个场景 |
| `shots` | 引擎、你 | `[{id, f0, f1, lyric?, camera?, need?, …}]`，`R.shotOf(sf)` 按帧找镜头；除 id/f0/f1 外的字段随你写（分镜笔记） |
| `cuts` | 引擎、转场关 | 镜头之间的转场，见 engine.md |
| `incamera` | 转场关 | 镜头内的大变化 `{shot, f0, f1, key, note}` |
| `emotes` | 引擎、体素关 V7 | 表情符号 `{who, g, f0, f1, dx}` |
| `grade`、`grade_why` | 引擎、调色关 | 按段落 / 场景变的色调，见下面「grade」；`grade_why` 是 `{"L4 P06": "原因"}`，故意不按常见走法来时写 |
| `events` | 钩子关 | `[{f, what}]`：动作轨、转场、表情以外的画面事件（镜头揭示、片名出现、道具亮起、新东西入画），开场 5 秒、没词的长段、人声进来那一拍靠它们和动作、转场一起过钩子关。登记了就要真的做出来 |
| `tracks` | 引擎、动作关 | 动作轨，见 engine.md |
| `extra_actions` | 引擎 | `{名字: [动作…]}`：轨里没有、但要手动 `pose` 的动作 |
| `sizes` | 体素关 V1 | `{名字: {scale, why}}`：故意放大缩小的角色（巨人、远处的倒影） |
| `occlude` | 体素关 V2 | `[{who, f0, f1, why}]`：故意让脚被挡住（站在草丛里、躲在墙后） |
| `treadmill` | 体素关 V3 | `[{who, f0, f1, why}]`：故意原地走（跑步机、梦里走不动） |
| `handoffs`、`handoff_cards` | 接力 | 见 relay.md；单曲 MV 留空 |

`ACTIONS.json` 由 `python tools/run.py actions` 从 `tracks` 生成；想要静止的地方在里面加 `holds: [{who, from, to, why}]`（秒，项目本地时间）。

## grade（调色）

一串关键帧，引擎在后期（移轴、泛光之后、暗角之前）对整帧调色：场景和角色一起调，字幕不受影响。

```json
"grade": [
  {"f": 0,    "exp": 0.75, "sat": 0.8,  "temp": -0.6, "shadow": "#28345a", "shadowAmt": 0.2, "vig": 0.4, "why": "前奏：雨夜，冷、暗、灰"},
  {"f": 610,  "exp": 0.9,  "sat": 0.95, "temp": -0.2, "ease": 300, "why": "导歌：一路亮起来"},
  {"f": 922,  "exp": 1.08, "con": 1.1, "sat": 1.18, "temp": 0.45, "hi": "#ffd9a0", "hiAmt": 0.12, "vig": 0.2, "why": "副歌 1：放开"},
  {"f": 3070, "exp": 0.6,  "con": 1.18, "sat": 0.75, "temp": -0.9, "shadow": "#203060", "shadowAmt": 0.25, "vig": 0.45, "dark": true, "why": "桥段：夜里，只留窗和路灯是暖的"}
]
```

| 参数 | 中性值 | 范围（调色关 L2） | 作用 |
|---|---|---|---|
| `f` | — | — | 全曲帧号。从这一帧起换成这个色调；放在段落的转场关键帧上最自然 |
| `ease` | 0 | ≥ 0 | 用多少帧从上一个色调过渡过来；0 = 这一帧直接换（配转场），几百帧 = 一整段慢慢变（导歌亮起来、天慢慢黑） |
| `exp` | 1 | 0.35–1.8 | 曝光（整体明暗） |
| `con` | 1 | 0.6–1.6 | 对比 |
| `sat` | 1 | 0–2 | 饱和度；0 是黑白（回忆、梦） |
| `temp` | 0 | −2–2 | 冷暖，正数偏暖（橙）、负数偏冷（蓝） |
| `tint` | 0 | −2–2 | 正数偏绿、负数偏品红 |
| `shadow`、`shadowAmt` | `#808080`、0 | 0–0.6 | 暗部染什么颜色、染多少（夜景暗部偏蓝紫） |
| `hi`、`hiAmt` | `#808080`、0 | 0–0.6 | 亮部染什么颜色、染多少（黄昏亮部偏金） |
| `vig` | 0.28 | 0–0.7 | 暗角强度 |
| `dark` | false | — | 这一段是故意压暗的：体素关 V6 的近黑像素放宽到 8% |
| `why` | — | — | 这个色调为什么（写给人看，也帮你自己检查是不是跟着段落走） |

没写的参数用中性值（不是沿用上一个关键帧），所以每个关键帧把这一段要的值写全。全中性 = 不调色，画面和没有 `grade` 时一模一样。
镜头里的短变化（一闪、渐暗、回忆段的褪色）不写在这里：`setupShot` 返回 `grade: {exp, sat, …}`，叠加在段落色调上（`exp`、`con`、`sat` 相乘，`temp`、`tint` 相加，其余覆盖）。
